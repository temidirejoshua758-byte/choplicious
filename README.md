# Choplicious Website

A static, responsive small-chops website for GitHub Pages.

## Included
- Home
- Small Chops menu with suggested launch prices
- Solo / Classic / Premium / Party packages
- Fast Food + Zobo
- About
- Contact / WhatsApp ordering
- Shopping cart stored in browser localStorage
- Responsive mobile navigation
- GitHub Actions deployment workflow
- Choplicious brand photography supplied by the owner

## Before launch
1. Confirm the prices against your actual ingredient, packaging, labour and delivery costs.
2. In `script.js`, change `PHONE` if the WhatsApp ordering number changes.
3. Replace or add any final business address/social links.
4. Add the folder to a GitHub repository and enable GitHub Pages with GitHub Actions.
